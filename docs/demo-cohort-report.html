Methodology. All drive data is synthetic — physically-parameterised sensor windows generated the same way as the app's own Demo Drive and ML training-data pipeline — anchored to real coordinates from the City of Bellevue's public MyBellevue 311 feed (158 real pothole reports, 1,256 real road-maintenance reports, zips 98005–98008). Heuristic-cohort events were produced by the Phase-1 hand-tuned threshold classifier; AI-cohort events are the genuine output of classifyWithModel run against extracted feature vectors — not fabricated numbers. Model metrics are the real results of the training run in ml/training/train.py, synced automatically via ml/export/sync_to_app.mjs. No real users or real drives are represented.
